{% translate "Regulamin serwisu Szron" %}

{% translate "Wersja demonstracyjna · 31 października 2026 r." %}

{% translate "Szron jest projektem demonstracyjnym sklepu i wypożyczalni. Ten regulamin opisuje działającą wersję serwisu. Nie przyjmujemy rzeczywistych zamówień, płatności ani rezerwacji." %}

{% translate "1. O serwisie" %}

{% translate "Serwis pozwala przeglądać katalog sprzętu zimowego, filtrować oferty, prowadzić konto klienta, zapisywać produkty w ulubionych i tworzyć koszyk. Nazwa sklepu, lokalizacje i dane kontaktowe są fikcyjne." %}

{% translate "2. Konto klienta" %}

{% translate "Rejestracja wymaga wybrania loginu i hasła. Zalogowany użytkownik może edytować imię, nazwisko, adres e-mail i telefon w zakładce „Dane profilu”. Dane kontaktowe są opcjonalne. Nie udostępniaj hasła innym osobom." %}

{% translate "3. Katalog i informacje o sprzęcie" %}

{% translate "Nazwy modeli i ich oznaczone parametry są demonstracyjne. Zdjęcia przedstawiają rzeczywiste produkty referencyjne. Pokazane ceny i dostępność pochodzą z lokalnej bazy projektu; nie stanowią aktywnej oferty rzeczywistego sklepu." %}

{% translate "4. Koszyk i ulubione" %}

{% translate "Koszyk i ulubione są przypisane do konta. Dodanie produktu nie rezerwuje sprzętu, nie zmniejsza stanu magazynowego i nie oznacza zakupu. Cena i dostępność mogą się zmienić. Produkty ukryte przez administratora nie są pokazywane w ulubionych." %}

{% translate "5. Zamówienia, płatności i wypożyczanie" %}

{% translate "Można składać demonstracyjne zamówienia zakupowe i rezerwować wypożyczenia. Zamówienie zmniejsza lokalny stan sprzedaży. Dostępne są odbiór osobisty lub demonstracyjna dostawa kurierem za pobraniem. Nie pobieramy płatności online, nie wysyłamy paczek i nie zawieramy rzeczywistych umów. Statusy i historię sprawdzisz na swoim koncie." %}

{% translate "6. Zwroty i zgłaszanie problemów" %}

{% translate "Zwroty zakupionych produktów nie są jeszcze obsługiwane. Nowe zamówienie można anulować przed rozpoczęciem przygotowania, co przywraca produkty na stan. Zwrot wypożyczonego sprzętu rejestruje obsługa wypożyczalni. Dane kontaktowe są demonstracyjne." %}

{% translate "7. Dane profilu" %}

{% translate "Dane konta, koszyka i ulubionych są przechowywane w lokalnej bazie projektu. Dane kontaktowe można zmienić lub wyczyścić w profilu. Do testów używaj danych przykładowych; nie wpisuj danych płatniczych ani innych poufnych informacji." %}

{% translate "8. Korzystanie z serwisu" %}

{% translate "Korzystaj z konta zgodnie z jego uprawnieniami. Nie próbuj uzyskiwać dostępu do cudzych danych ani do funkcji administracyjnych bez przyznanych uprawnień." %}

{% translate "9. Dalszy rozwój" %}

{% translate "Przed uruchomieniem rzeczywistej sprzedaży lub wypożyczalni regulamin wymaga uzupełnienia o prawdziwe dane sprzedawcy oraz właściwe warunki zamówień, płatności, dostaw, zwrotów, reklamacji i ochrony danych." %}
